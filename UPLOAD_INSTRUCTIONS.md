# GitHub Upload Instructions

Repository:

https://github.com/EricRathod/Nuclear-Innovation-Investment-Dashboard

## Upload

1. Extract this ZIP file on your computer.
2. Open the repository link above.
3. Select **Add file > Upload files**.
4. Drag all extracted project items into the upload area:
   - `data`
   - `images`
   - `notebooks`
   - `powerbi`
   - `.gitignore`
   - `README.md`
   - `requirements.txt`
5. Enter the commit message:

   `Add nuclear innovation investment dashboard project`

6. Select **Commit changes**.

After uploading, open the repository page and confirm that the README displays the three dashboard screenshots.
